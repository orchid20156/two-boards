# Put Two Boards on GitHub Pages

1. Create a new public repository on github.com (for example `two-boards`).
2. Upload everything in this folder to the repository root (drag the files into the web page, or use git). The single file `two-boards.html` also works alone: rename it to `index.html`.
3. In the repository go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute your site is live at `https://<your-name>.github.io/two-boards/`.

## Saving progress
- Progress, game records and puzzles are saved in each browser automatically.
- To use your progress on other devices, open the **👤 Player** menu:
  - **Connect GitHub**: paste a token that has only the `gist` permission. Your save goes into a private gist. Connect the same token on your other devices.
  - Or use **Download save file / Copy save code** and import it on the other device.
- The token is stored only in your browser and is never included in the save.
